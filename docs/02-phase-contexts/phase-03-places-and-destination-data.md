# Phase 03 — Places and Destination Data

The Trip Planner needs a structured way to store and manage places users want to visit.

Investigate individually:
- Adding, editing, and deleting a place.
- Place information and metadata.
- Place categories.
- Address and geographical coordinates.
- Descriptions and images.
- Estimated visit duration.
- Personal notes.
- Bucket List management.
- Adding places to a trip.
- Moving places between the Bucket List and itinerary.

Understand the difference between a place as a domain entity and a scheduled itinerary activity. Explore data modelling, geospatial information, validation, relationships, and reuse by other modules.
