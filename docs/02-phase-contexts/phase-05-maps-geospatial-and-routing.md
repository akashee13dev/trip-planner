# Phase 05 — Maps, Geospatial Data, and Routing

The map experience should help users understand the geographical relationship between itinerary locations and organize routes.

Investigate individually:
- Displaying trip locations on a map.
- Map markers for itinerary places.
- Day-wise map views.
- Selecting and highlighting a place.
- Ordering locations into a route.
- Distance calculation.
- Travel-time estimation.
- Route visualization.
- Geographical coordinates and storage.
- Map provider integration.
- Member location sharing.
- Last-shared member location.

Teach geospatial concepts, latitude/longitude, spatial databases, routing algorithms, external map APIs, and limitations. Distinguish straight-line distance from actual road or travel distance.
