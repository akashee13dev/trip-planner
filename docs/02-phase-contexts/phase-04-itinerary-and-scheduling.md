# Phase 04 — Itinerary and Scheduling

This module converts a collection of places into an organized day-wise travel plan.

Investigate individually:
- Creating an itinerary.
- Day-wise organization.
- Adding activities to a day.
- Scheduling dates and times.
- Reordering activities.
- Moving activities between days.
- Unscheduled Bucket List.
- Estimated activity duration.
- Time conflicts and overlapping schedules.
- Editing and removing activities.
- Group collaboration on itinerary changes.
- Approving suggestions.

Understand how itinerary systems represent scheduled activities, calculate time, maintain ordering, handle conflicting changes, and preserve consistency when multiple members modify a trip. Distinguish a place, an itinerary item, and an actual visit.
